Current direction

I am building the current pack for a group of friends using standard Forge. The aim is a longer, fuller progression that grows out of Minecraft instead of feeling like several unrelated games bolted together.

Planned progression changes

  • Bundles can become the starting point for a pouch and backpack progression.
  • Raw ingredients provide less benefit so proper meals are worth making.
  • Farming, fishing, wildlife, storage, and exploration feed into the same progression.
  • Custom recipes remain understandable and visually consistent with vanilla items.

Current project state

Building and testing: the Minecraft version, complete mod list, recipe changes, and export will be recorded together once the core set works.
