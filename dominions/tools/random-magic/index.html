Use only when the pool matches

The model assumes independent slots, uniform outcomes, and replacement between rolls. Do not use it unchanged for linked randoms, non-uniform weights, paths excluded by an earlier roll, all-path randoms with a different structure, or modded recruitment that changes the pool.
