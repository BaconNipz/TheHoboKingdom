Z-Land quick-start project

Core rules still required: this quick-start material helps us play, but it does not replace the Z-Land rulebook. Every public file will say so.

The opening plan

The first session will use prepared characters so the group can learn the game before the longer campaign begins. The main campaign then starts on the day of the infection, with the players portraying versions of themselves and me remaining as GM.

Material being prepared

  • A one-page introduction explaining the situation and how the game works.
  • A darker opening narration that can be read aloud at the table.
  • A concise explanation of the infection without revealing more than the characters should know.
  • Prepared-character material for the learning session.
  • Physical items that can be handed to players when their characters recover something important.
  • Other documents, notices, maps, and clues that make the out-of-character table reflect what is happening in the story.

After each session

I want the project to grow from what actually happens at the table. After each session I can add rules notes, consequences, handouts, and setting material once I have had time to judge what worked.

Public release standard

The first public bundle will be labelled as a playtest and include its version and date. It will state that the core rules are required and will not include anything that reveals future GM plans.
