Rules boundary: the quick-start material supports play but does not replace the Z-Land core rules. Any public file must say this clearly.

The opening plan

The first session uses prepared characters so the group can learn how the game behaves before the long campaign begins. The main campaign then starts on the day of the infection, with the players portraying versions of themselves while the user remains the GM.

Material being prepared

  • A one-page introduction explaining the situation and how the game works.
  • A darker opening narration that can be read aloud at the table.
  • A concise explanation of the infection without revealing more than the characters should know.
  • Prepared-character material for the learning session.
  • Physical items that can be handed to players when their characters recover something important.
  • Other documents, notices, maps, and clues that make the out-of-character table reflect what is happening in the story.

After each session

The project should grow from what actually happened at the table. New rules notes, consequences, handouts, and setting material can be added after a session, once there has been enough time to think about what worked before the next game.

Public release standard

The first public bundle should be labelled as a playtest, list the version and date, explain that the core rules are still required, and separate player-facing pages from anything that could reveal future GM plans.
