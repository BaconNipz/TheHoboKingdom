Projects/Tabletop/The Last of Us expansion

Unofficial fan expansion

The Last of Us: Escape the Dark

Character overhauls, hang-up tracks, breakthrough rewards, equipment, crafting, chapter cards, and printable components designed around the official game's existing language.

In developmentRequires the base gameBlack-and-white card setNot a commercial release

Completed character work

Joel, Ellie, and Bill have received complete overhaul work covering their character identity, hang-up progression, breakthrough rewards, and unique traits. Wording has been revised to match the official game's style and to remove mechanics, such as shield-die phrasing, that do not belong in the system being used.

Current development

  • Finish the crafting system and review the value of every new item.
  • Continue the remaining character overhauls using the same structure as the completed set.
  • Check new equipment and chapter cards against the official turn structure and terminology.
  • Keep every printable card versioned so an old draft cannot be confused with the accepted set.
  • Prepare blank templates separately from finished fan cards.

Publishing boundary

The public page must identify the project as an unofficial fan expansion, state that the original game is required, and use only project-created text and artwork that can properly be shared. It should never present copied official components as part of the download.

Not yet a stable download: the character work is substantial, but the crafting and item review must be finished before the full booster is presented as complete.
