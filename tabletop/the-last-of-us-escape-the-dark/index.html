Unofficial fan expansion

The Last of Us: Escape the Dark

I am expanding the character work, hang-up tracks, breakthrough rewards, equipment, crafting, chapter cards, and printable pieces while keeping to the language of the original game.

In developmentRequires the base gameBlack-and-white card setNot a commercial release

Completed character work

Joel, Ellie, and Bill now have complete overhauls covering their character identity, hang-up progression, breakthrough rewards, and unique traits. I revised the wording to match the original game's style and removed mechanics, such as shield-die wording, that do not belong in this system.

Current development

  • Finish the crafting system and review the value of every new item.
  • Continue the remaining character overhauls using the same structure as the completed set.
  • Check new equipment and chapter cards against the official turn structure and terminology.
  • Keep every printable card versioned so an old draft cannot be confused with the accepted set.
  • Prepare blank templates separately from finished fan cards.

Publishing boundary

Every public file will identify this as an unofficial fan expansion and state that the original game is required. A download will contain only text and artwork I can properly share, never copied official components.

Not ready to download: the character work is well advanced, but I still need to finish the crafting and item review before calling the full booster complete.
