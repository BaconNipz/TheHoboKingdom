How releases will work

  • Large ZIP files and application builds will live in GitHub Releases rather than inside the website.
  • Every download will include a version, date, supported game version, and short installation note.
  • Older stable versions can remain available when a new build needs to be rolled back.
  • Printable PDFs will be grouped by the project they belong to.
